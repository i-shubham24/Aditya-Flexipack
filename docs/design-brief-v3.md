# Design brief v3: Aardvark's craft, Aditya's world

Reference: aardvarkbookclub.com (Webflow, GSAP, ScrollTrigger, SplitText, Lenis, Barba).
We adapt its *system*, never its content, colours or illustrations.

| Aardvark device | Aditya adaptation |
|---|---|
| Brand-colour loader + logo, organic shape swoop exit | Deep wine field, Aditya logo, a crimson film-shaped sweep that clears upward (once per session) |
| Logo left, soft nav tabs centre, split CTA (label block + arrow block) | Same anatomy: logo, soft foil tabs, split crimson CTA |
| Chunky display (Champ) + friendly body (Degular) + handwriting notes | Cabinet Grotesk 800 + General Sans (both Indian Type Foundry) + Caveat as crimson proof-pen notes |
| Flat bold colour sections as 40px-radius panels, tonal organic contours inside | Crimson, wine, foil silver, paper white panels; tonal contour layers in the section's own hue |
| Yellow hero with flying-books image sequence | Crimson hero with the tear-open pouch frame sequence |
| "Our Nov books" coloured card carousel | "Our products" coloured card carousel with real plant photos |
| "How it works" fanned multicolour cards | Partnership process as four cards in cyan, magenta, yellow and key (CMYK) |
| Pinned unboxing sequence | Pinned "Every pack starts flat": the pouch tears and fans into its laminate layers |
| Giant stacked genre list | Kept as the liked pinned aisle switch, restyled |
| "Why Aardvark?" emblem with arc text + stickers | "Why Aditya?" plant-photo seal with arc text + die-cut label stickers (Why Us list) |
| Page panel lifts off a deep footer | Same, over a deep wine footer |

Kept from v2 because the user liked them: the web-path timeline, the aisle scroll-and-switch, the shelf finale.
Removed: live 3D hero, slit lanes, batch-code panel, stacked pillar cards.
