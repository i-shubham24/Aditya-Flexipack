# Old WordPress site media catalogue (adityaflexipack.com)

Every image found by the crawl of the old site, converted for the Next.js project and stored under `public/media/old/`. This file is a reference only; nothing in `src/` uses these files yet.

## Summary

- URLs crawled: 105 (all downloaded, 0 failed, no fallback variants needed)
- Exact duplicates skipped: 1
- Kept: 104 files (6 SVG copied as-is, 98 WebP, of which 1 animated)
- Marked as UI icons or decorative UI shapes: 14
- Size on disk: 7.35 MB (originals totalled about 65.70 MB for the non-SVG files)

## How the files were produced

- Format: WebP quality 80, max width 2000 px, never enlarged. EXIF orientation applied.
- SVG icons copied unchanged. The loader GIF is an animated WebP (17 frames, original timing kept).
- Folder = first old page that used the image (first match in `crawl/map.tsv`); underscores in page slugs become hyphens (`products_films` -> `products-films`). Images used on 4 or more old pages go to `shared/`.
- Alpha: "yes" means real transparency was kept. "yes (corners only)" means the source had a few transparent or anti-aliased pixels at rounded corners and the alpha channel was kept for them. "no" means fully opaque, so the alpha channel was dropped to save bytes.
- Pixel size is the size of the new file. If it was scaled down, the original size is shown as "src".
- Old pages are listed with the slugs used in the crawl.
- Description prefixes: "ICON" = tiny UI icon or decorative UI shape (not content). "page-header banner" = wide photo that was faded to white on the left and has a white notch baked in, built to sit under old-site page titles. "mockup" = rendered design mockup, not a photo of a real product. Two mockups were generated by an AI image tool (their original filenames start with "ChatGPT-Image"). "stock photo" = generic stock imagery.
